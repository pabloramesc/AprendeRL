# C51

[Back to the algorithm index](../algorithms.md)

**Policy classification:** Off-policy. C51 learns from uniformly replayed
transitions collected by earlier epsilon-greedy behavior policies.

**Use when:** observations are numeric `Box` vectors or tensors, actions are
`Discrete`, and representing uncertainty in returns is useful while retaining
the small one-step DQN training loop.

## From scalar values to a categorical distribution

DQN predicts one scalar action value. C51 instead predicts a categorical return
distribution for every action on `atoms` evenly spaced values between `v_min`
and `v_max`:

$$
z_i = v_{\min} + i\Delta z,
\qquad
\Delta z = \frac{v_{\max}-v_{\min}}{N-1},
\qquad i=0,\ldots,N-1.
$$

The network emits logits with shape `(batch_size, action_count, atoms)`. A
softmax over the atom dimension gives $p_\theta(z_i\mid s,a)$, and the expected
action value used for exploration and prediction is

$$
Q_\theta(s,a)=\sum_{i=0}^{N-1}z_i p_\theta(z_i\mid s,a).
$$

The default `CategoricalQNetwork` flattens each observation, applies two
128-unit ReLU layers, and returns one logit per action and atom. The default
support has 51 atoms from $-10$ to $10$; the support should be widened or
rescaled when the task's discounted returns lie substantially outside that
interval.

## Distributional Bellman target

For a sampled transition, C51 first selects the next action from expected
values. With `double_dqn=False`, the target network selects and evaluates the
action. With `double_dqn=True`, the online network selects it and the target
network still supplies its distribution:

$$
a^* =
\begin{cases}
\arg\max_a Q_{\theta^-}(s',a), & \text{standard target},\\
\arg\max_a Q_\theta(s',a), & \text{Double-DQN target}.
\end{cases}
$$

Each atom of the selected target distribution is shifted by the one-step
Bellman update,

$$
\tilde z_j = r + \gamma(1-d)z_j,
$$

where $d=1$ only for a true Gymnasium `terminated` transition. A `truncated`
transition therefore continues to bootstrap. Because the shifted atoms do not
usually land on the fixed support, their probability mass is clipped to
$[v_{\min},v_{\max}]$ and distributed linearly between the adjacent support
atoms. Denote that projection by $\Phi$.

For the recorded action, the network minimizes categorical cross-entropy:

$$
\mathcal L_{\mathrm{C51}}
=-\frac{1}{B}\sum_{b=1}^{B}\sum_{i=0}^{N-1}
(\Phi T Z_b)_i\log p_\theta(z_i\mid s_b,a_b).
$$

Optimization, replay timing, hard target updates, gradient clipping, and the
epsilon schedule are inherited from `DQN`. See the [DQN guide](dqn.md) for
those shared details.

## Usage

```python
import gymnasium as gym

from aprenderl import C51, C51Config

env = gym.make("CartPole-v1")
config = C51Config(
    atoms=51,
    v_min=-10.0,
    v_max=10.0,
    buffer_size=20_000,
    learning_starts=1_000,
    double_dqn=True,
)
agent = C51(env, config=config).learn(20_000)

action = agent.predict(env.reset()[0], deterministic=True)
agent.save("c51.pt")
restored = C51.load("c51.pt", env)
```

A custom `network` must accept an observation batch and return logits shaped
`(batch_size, action_count, atoms)`. When a checkpoint used a custom network,
the same architecture must be supplied as `network=...` when loading it.

The implementation and projection helper are in
[`src/aprenderl/algorithms/c51.py`](../../src/aprenderl/algorithms/c51.py), and
the default network is in
[`src/aprenderl/networks/distributional.py`](../../src/aprenderl/networks/distributional.py).
See the runnable [`C51 example`](../../examples/c51.ipynb) and the
standalone [`C51 study notebook`](../../study/05_distributional_rl/01_c51.ipynb).
