# v0.2 — Classical RL and policy gradients

AprendeRL 0.2 expands the readable DQN foundation with tabular temporal-
difference methods and a complete on-policy progression from REINFORCE to
Advantage Actor-Critic. The policy-gradient algorithms support both discrete
and continuous actions while retaining small, explicit training loops.

## Highlights

- Tabular Q-Learning and SARSA with configurable epsilon-greedy exploration,
  offset `Discrete` spaces, JSON checkpoints, and correct time-limit
  bootstrapping.
- REINFORCE in its vanilla form or with an optional learned state-value
  baseline, complete-episode batching, normalized policy weights, and entropy
  regularization.
- One-step Actor-Critic with separate policy and value networks, TD advantages,
  gradient clipping, and fixed-length on-policy rollouts.
- Single-environment A2C with generalized advantage estimation, optional
  advantage normalization, configurable entropy and value-loss coefficients,
  and multi-step value targets.
- Categorical policies for `Discrete` actions plus diagonal-Gaussian policies
  for continuous `Box` actions. Finite bounds use a `tanh`-squashed Gaussian;
  fully unbounded spaces use a plain Gaussian.
- Correct handling of Gymnasium `terminated` and `truncated` signals throughout
  value bootstrapping and GAE recursion.
- Custom policy, value, and Q-network support with validated output shapes and
  checkpoint metadata for observation spaces, action shapes, and action bounds.
- Self-contained mathematical guides and nine runnable notebooks covering DQN,
  tabular methods, policy gradients, and continuous control on Pendulum.
- Expanded unit, interaction, checkpoint, and learning tests for every public
  algorithm and reusable component.

See the README for minimal usage, the algorithm guides for the update
equations, and the roadmap for the next planned methods.
