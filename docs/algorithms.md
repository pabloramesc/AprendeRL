## Notation

At time step $t$, the agent observes state $s_t$, chooses action $a_t$, receives
reward $r_{t+1}$, and reaches $s_{t+1}$. The discounted return is

$$
G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}, \qquad 0 \leq \gamma \leq 1.
$$

The action-value function is the expected return after taking $a$ in $s$:

$$
Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t=s, a_t=a].
$$

The optimal action-value function satisfies the Bellman optimality equation:

$$
Q^*(s,a) = \mathbb{E}\left[r_{t+1}
+ \gamma \max_{a'} Q^*(s_{t+1},a') \mid s_t=s,a_t=a\right].
$$

Q-Learning and DQN approximate this fixed point with greedy one-step
temporal-difference targets. SARSA uses a one-step target from its current
behavior policy. REINFORCE instead optimizes a parameterized policy directly
from sampled returns.

### Termination versus truncation

Let $d_t=1$ only when the environment reports `terminated`; otherwise $d_t=0$.
The shared target form is

$$
y_t = r_{t+1} + \gamma(1-d_t)\max_{a'}Q(s_{t+1},a').
$$

A true terminal state has no future value. A time-limit `truncated` transition
still bootstraps because the underlying MDP did not terminate.

### Epsilon-greedy exploration

During Q-Learning, SARSA, and DQN training, actions use

$$
a_t =
\begin{cases}
\text{uniform random action}, & u < \varepsilon_t,\\
\arg\max_a Q(s_t,a), & \text{otherwise},
\end{cases}
\qquad u \sim \mathcal{U}(0,1).
$$

Epsilon decreases linearly for $T$ environment steps, then remains at its final
value:

$$
\varepsilon_t = \varepsilon_{\mathrm{start}} +
\min\left(\frac{t}{T},1\right)
\left(\varepsilon_{\mathrm{final}}-\varepsilon_{\mathrm{start}}\right).
$$

Deterministic prediction always uses the greedy action.

## Off-policy algorithms

An **off-policy** algorithm can learn about a target policy from transitions
generated by a different behavior policy. This lets it reuse older experience
or learn a greedy policy while collecting exploratory actions.

### Tabular Q-Learning

Learns action values in a table using one-step temporal-difference updates and
epsilon-greedy exploration. [Read the full guide](algorithms/q_learning.md).

### Deep Q-Network (DQN)

Approximates action values with a neural network trained from replayed
transitions. [Read the full guide](algorithms/dqn.md).

## On-policy algorithms

An **on-policy** algorithm updates the same policy that generated its current
training trajectories. Once the policy changes, old trajectories are generally
not reused for later updates.

### Tabular SARSA

Learns action values in a table using the next action selected by the current
epsilon-greedy behavior policy. [Read the full guide](algorithms/sarsa.md).

### REINFORCE

Optimizes a categorical policy directly from the discounted returns of complete
episodes. [Read the full guide](algorithms/reinforce.md).
