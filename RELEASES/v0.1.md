# v0.1 — Core API and vanilla DQN

AprendeRL 0.1 establishes the small, readable foundation for the project and
ships a complete vanilla DQN implementation for single Gymnasium environments
with vector observations and discrete actions.

## Highlights

- Familiar, typed algorithm APIs with reusable off-policy and on-policy bases.
- Vanilla DQN with replay learning, a target network, gradient clipping, and a
  configurable epsilon-greedy exploration schedule.
- Correct handling of Gymnasium's separate `terminated` and `truncated`
  signals, including value bootstrapping across time-limit truncations.
- PyTorch network components with support for custom Q-networks.
- Reproducible seeding, device selection, callbacks, scalar logging, policy
  evaluation, and checkpoint save/load support.
- Compact replay and rollout buffers plus reusable categorical distributions
  and environment wrappers.
- A runnable CartPole example and a test suite covering the public components
  and end-to-end DQN learning.

## Install

AprendeRL requires Python 3.10 or newer.

```bash
python -m pip install -e ".[dev]"
```

See the README for the minimal DQN example and the roadmap for planned
algorithms.
